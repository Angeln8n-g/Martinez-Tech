## 🌟 Descripción General

**Martínez Tech** es una solución full-stack completa que unifica la cara pública de la empresa (sitio web de alta conversión con catálogo y estimador rápido) con un robusto **Sistema CRM y de Operaciones Técnicas**. 

Diseñado específicamente para el sector de integración tecnológica en República Dominicana y Latinoamérica, optimiza el ciclo de vida completo de cada proyecto: desde el primer contacto del cliente, levantamiento técnico y cotización con cálculo de margen en vivo, hasta la ejecución en campo con actas de entrega fotográficas, firma digital en pantalla y control de cobranzas.

---

## ⚡ Módulos y Características Principales

### 🌐 1. Sitio Web Público de Alta Conversión
- **Diseño Moderno & Responsive**: Presentación corporativa con identidad de marca prémium (modo Claro y Oscuro).
- **Estimador Rápido de Presupuestos**: Cotizador interactivo en línea para que los clientes obtengan presupuestos estimados inmediatos y soliciten visitas técnicas.
- **Portafolio de Proyectos**: Galería filtrable con especificaciones técnicas, fotos de alta resolución y testimonios.
- **Botón Flotante de WhatsApp**: Enlace directo y contextualizado con el equipo comercial.

### ✍️ 2. Firma Digital en Pantalla & Aprobación en Línea
- **Pad de Firma Táctil y Mouse**: Canvas vectorial de alta precisión compatible con smartphones, tablets y computadoras de escritorio.
- **Certificación en Hoja Membretada**: Estampado digital de firma con nombre, fecha, hora y sello de verificación en presupuestos y actas de entrega.
- **Automatización de Estados**: Al firmar, el presupuesto pasa a `Aceptada & Firmada` y la negociación en el CRM avanza automáticamente a la fase de instalación.

### 📋 3. Órdenes de Trabajo & Actas de Entrega Técnica (Conduces)
- **Checklist de Conformidad Técnica**: Verificación de calidad paso a paso (canalización, ponchado, configuración P2P, pruebas).
- **Galería de Evidencia Fotográfica (Antes vs Después)**:
  - Subida directa desde cámara del móvil o galería de fotos (conversión automática a Base64).
  - Selector de fotos de muestra por tipo de servicio.
  - Visor interactivo **Lightbox en pantalla completa** con ampliación y modo comparativo.
- **Documento Membretado Oficial**: Formato formal optimizado para impresión y exportación en PDF.

### 📲 4. Centro de Mensajería WhatsApp 1-Clic
- **5 Plantillas Inteligentes con Variables Automáticas**:
  1. 📄 *Envío de Cotización Formal* (código, total, vigencia y garantías).
  2. 📅 *Confirmación de Visita Técnica* (fecha, hora, técnico asignado y dirección).
  3. 💳 *Recordatorio de Saldo Pendiente* (desglose de abonos, saldo y cuentas bancarias).
  4. 🧾 *Comprobante de Pago y Recibo Oficial*.
  5. ⭐️ *Solicitud de Reseña de 5 Estrellas en Google*.
- Acciones de **"Abrir en WhatsApp"** y **"Copiar Texto"**.

### 💰 5. Calculadora de Costos & Margen de Rentabilidad (Confidencial Admin)
- **Análisis Financiero en Tiempo Real en el Cotizador**:
  - Costo de compra de materiales e insumos (`costPrice`).
  - Total de venta al cliente.
  - **Ganancia Bruta (RD$)** y **Margen Neto (%)**.
  - **Semáforo Financiero**: 🟢 >35% (Excelente), 🟡 20-35% (Aceptable), 🔴 <20% (Bajo Margen).
  - Modo confidencial conmutador (nunca visible en el documento del cliente).

### 📊 6. Reportes Financieros & Exportador a Excel / CSV
- **Panel de Métricas Ejecutivas**: Total Cotizado, Ingresos Cobrados en Caja y **Cuentas por Cobrar**.
- **Tabla de Saldos Pendientes**: Detalle por cliente de abonos realizados y balances pendientes de cobro.
- **Exportación 1-Clic a archivos `.CSV`**:
  - 📥 *Cotizaciones*
  - 📥 *Recibos de Cobro*
  - 📥 *Cuentas por Cobrar*
  - 📥 *Directorio de Clientes*

### 💳 7. Gestión de Pagos & Recibos de Cobro
- Registro de anticipos y liquidaciones con selección de método de pago (*Transferencia, Efectivo, Tarjeta, Cheque*).
- Emisión de **Recibos Oficiales Membretados** con código único (`REC-2026-XXX`), datos fiscales y descarga PDF.

### 📅 8. Agenda Técnica & Calendario
- Programación de levantamientos, instalaciones y mantenimientos correctivos/preventivos con asignación de técnicos y filtros por estado.

### 🗂️ 9. Embudo de Negociaciones Kanban (CRM)
- Pipeline visual con 8 etapas operativas:
  `1. Prospecto` ➔ `2. Levantamiento` ➔ `3. Cotizado` ➔ `4. Negociación` ➔ `5. Aprobado` ➔ `6. En Instalación` ➔ `7. Finalizado` ➔ `8. Cancelado`.

### 📦 10. Catálogo de Equipos & Precios
- Base de datos de productos con precios de venta, costos, categorías y especificaciones técnicas.

## 🚀 Requisitos Previos e Instalación

### Requisitos:
- **Node.js**: Versión 18.x o 20.x LTS o superior.
- **NPM**: Versión 9.x o superior.

### 1. Clonar el repositorio:
```bash
git clone https://github.com/tu-usuario/martinez-tech.git
cd martinez-tech
```

### 2. Instalar dependencias:
```bash
npm install
```

### 3. Iniciar en modo desarrollo (Frontend + Backend concurrentes):
```bash
npm run dev:all
```
- **Web & CRM**: `http://localhost:3000`
- **Backend API REST**: `http://localhost:5000`

## 🛠️ Scripts Disponibles

| Comando | Descripción |
| :--- | :--- |
| `npm run dev:all` | Inicia simultáneamente el servidor backend (Node/Nodemon) y el frontend (Vite). |
| `npm run dev` | Inicia únicamente el servidor de desarrollo de Vite (puerto 3000). |
| `npm run server` | Inicia únicamente el servidor Express REST con auto-recarga `nodemon` (puerto 5000). |
| `npm run build` | Compila TypeScript y genera el empaquetado optimizado para producción en `/dist`. |
| `npm start` | Inicia el servidor Express en producción sirviendo la API y los archivos estáticos en un solo puerto. |
| `npm run preview` | Previsualiza localmente el build de producción generado por Vite. |

## 🌐 Despliegue a Producción

El sistema está configurado para un **despliegue unificado**: en producción, Express sirve la API `/api/*` y la aplicación React `/dist` desde un solo proceso.

### Opción A: Despliegue en Render / Railway
1. Conecta tu repositorio de GitHub en Render.
2. **Build Command**: `npm install && npm run build`
3. **Start Command**: `npm start`
4. Añade un **Persistent Disk** montado en `/server/data` para preservar la base de datos entre actualizaciones.

### Opción B: Servidor VPS Dedicado (Ubuntu + Nginx + PM2 + SSL)
```bash
# Compilar proyecto
npm run build

# Iniciar proceso en segundo plano con PM2
pm2 start server/index.js --name "martinez-tech"
pm2 save
pm2 startup
```
